# CH02 – SOLID Refactoring

## Giới thiệu
Dự án thực hành tái cấu trúc mã nguồn C# theo nguyên tắc SOLID và áp dụng các Design Pattern.

## Nội dung
- Phân tích các vi phạm SOLID.
- Tách `ClubManager` thành các service và repository.
- Áp dụng Factory, Decorator, Strategy và Observer.
- Hoàn thiện logic Domain và viết unit test.

## Công nghệ
- C#
- .NET
- xUnit
- Git và GitHub

## Cách chạy
Chạy kiểm thử:

```powershell
dotnet test Ch02.Refactor.sln
```

Chạy chương trình:

```powershell
dotnet run --project Ch02.Refactor
```
